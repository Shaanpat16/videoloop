# Drop videos here

Put `.mp4` / `.webm` / `.mov` files in this folder, commit, and push.
Render rebuilds and the screen picks them up on its own.

- **Order** is alphabetical. Prefix names to control it: `01-welcome.mp4`, `02-events.mp4`.
- **Size**: keep each file under 100 MB — GitHub rejects anything larger.
- **Format**: H.264 `.mp4` with AAC audio plays everywhere. Encode portrait as 1080x1920.

Removing a file from this folder removes it from the loop on the next push.
